# OZ Fitness Gym · Rutinas por QR (demo)

Demo de presentación: el alumno escanea el QR del gimnasio, elige nivel, objetivo y días, y obtiene su rutina con cada ejercicio explicado. Sin descargas ni registro.

- Sitio: https://oz.elyonhub.com.mx
- Todo vive en `index.html` (HTML, CSS y JS en un solo archivo).
- `qr/` contiene el QR con el distintivo OZ (PNG y SVG).
- `CNAME` le indica a GitHub Pages el subdominio.

Ejercicios, cantidades y números de equipo son de muestra; requieren revisión del equipo de Oz antes de usarse con alumnos.
